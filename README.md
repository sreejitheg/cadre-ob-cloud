# Cadre HMI Library

A maritime-inspired Ignition Perspective **parent project, component library, application frame
and screen generator**, built from stock Perspective components, with a wiki and gates that let the Cadre tools build,
validate and test screens from a JSON descriptor.

The question it answers: can a maritime navigation philosophy, parent project and component
library be built as our own stock parent project, and generated from a JSON descriptor? The answer,
with the evidence in [`wiki/`](wiki/index.md): yes; a rebuilt process overview places all 39 symbols
at exact pixel centres with the same states and readouts. A
small water treatment plant built on the library runs from the glass with every gate passing
([`wiki/11`](wiki/11-water-treatment-sample.md)).

Status: **🔨 Building**, usable for trials. Gateway `Ignition-PCS_DEV_Station`, Ignition 8.3.6;
projects `cadre_hmi_base` (parent), `cadre_hmi_wtp`, `cadre_hmi_sample`, `cadre_hmi_demo`.
Scope: process automation (COBD-010).

## 2. Quick Start

From the repository root (PowerShell; in Git Bash set `MSYS_NO_PATHCONV=1` first):

```bash
python tools/hmi/parent.py --out build --deploy
```

```bash
python tools/hmi/screen.py --project cadre_hmi_sample --descriptor screens/sample-pump-station.json --app-name Sample --out build --report workspace/reports/sample.json --deploy
```

```bash
python -m unittest discover -s tests
```

The sample renders at `http://localhost:8088/data/perspective/client/cadre_hmi_sample/pump-station`.

The water treatment sample: write its tag model and descriptors, then build, gate and deploy it.

```bash
python tools/plants/wtp.py
```

```bash
python tools/hmi/screen.py --project cadre_hmi_wtp --descriptor screens/wtp/overview.json --descriptor screens/wtp/intake.json --descriptor screens/wtp/filtration.json --descriptor screens/wtp/disinfection.json --app-name "Village WTP" --alarm-scope "*cadre_hmi_wtp*" --tags-file screens/wtp/tags.json --out build --report workspace/reports/wtp.json --deploy
```

It runs at `http://localhost:8088/data/perspective/client/cadre_hmi_wtp`.

## 4. Third-party Components

The module includes web components from the Apache-2.0 package `@oicl/openbridge-webcomponents`
2.0.0-next.155, and the library's design tokens and icon geometry are derived from the same package;
see [`NOTICE`](NOTICE). Every Perspective component, property, enumeration and binding shape traces to
the Ignition-Wiki registry (gate G1) or to a measurement on the gateway
([`wiki/07`](wiki/07-gateway-facts.md)). All components are original implementations; no third-party
module or project code is included apart from the pinned Apache-2.0 package.
